# نقطة الانهيار

**نقطة الانهيار** لعبة voxel عربية قصيرة مبنية بـRust وBevy لموضوع مسابقة Sub Qim Jam 2026: **Critical Point**. مدة الجولة المستهدفة 8–12 دقيقة.

يبدأ العالم هادئاً ومشرقاً، ثم يتحول بصرياً وصوتياً كلما ارتفعت نسبة الخطر. مهمتك جمع ثلاث شظايا استقرار، ثم اتخاذ القرار الذي يغيّر كل شيء:

- إخلاء الناس والعودة إلى المنارة قبل انتهاء 90 ثانية.
- النزول إلى النواة ومحاولة تثبيت العالم خلال 120 ثانية.

لا يوجد قتال. الخصم هو الوقت، الحفر غير المحسوب، الصدوع، الظلام والانهيارات.

## التشغيل

### نسخة Windows الجاهزة

فك ضغط **critical-point-windows.zip** وشغّل **critical_point.exe**. يجب إبقاء مجلد **assets** بجانب الملف التنفيذي.

### من المصدر

المتطلبات:

- Windows 10 أو 11 بنظام 64-bit.
- Rust 1.88 أو أحدث، أو rustup لقراءة **rust-toolchain.toml**.
- بطاقة رسومية تدعم Vulkan أو DirectX 12.

~~~powershell
cargo run --release
~~~

لبناء النسخة النهائية:

~~~powershell
cargo build --release
~~~

## التحكم

| الإدخال | الفعل |
|---|---|
| WASD أو الأسهم | الحركة حسب اتجاه الكاميرا |
| Shift | الركض |
| Space | القفز |
| زر الفأرة الأيسر مع الاستمرار | حفر الكتلة المستهدفة |
| زر الفأرة الأيمن | وضع كتلة دعم |
| E | التفاعل أو تأكيد الهدف |
| عجلة الفأرة | تقريب وإبعاد الكاميرا |
| سحب الزر الأوسط | تدوير الكاميرا |
| Q وE بعيداً عن نقاط التفاعل | تدوير الكاميرا |
| Esc | إيقاف مؤقت أو متابعة |

السقوط لا ينهي الجولة مباشرة؛ يعيد اللاعب إلى آخر نقطة آمنة ويضيف عقوبة إلى الخطر. عند بلوغ الخطر 100% ينتهي العالم.

## وضع التطوير

لا تظهر إعدادات توليد العالم للاعب العادي. لعرض المساعدة:

~~~powershell
target\release\critical_point.exe --help
~~~

ولتغيير عالم الاختبار فقط:

~~~powershell
cargo run --release -- --dev-world --seed 0xC17CA1 --radius 6 --preset balanced
~~~

الإعداد الافتراضي يستخدم بذرة ثابتة للمسابقة، مع ثلاث بلورات سردية مضمونة ومنع البلورات الإجرائية العشوائية من اختصار الحلقة.

## البنية التقنية

- **src/state.rs**: حالات التطبيق، الجلسة المركزية، التوازن والأحداث.
- **src/world.rs**: ذاكرة chunks المعدلة، raycast، إعادة بناء المناطق المتسخة والكاميرا.
- **src/player.rs**: الحركة والجاذبية والقفز والتصادم.
- **src/interaction.rs**: الحفر أحادي الكتلة والبناء الآمن.
- **src/gameplay.rs**: البلورات، الخطر، الانهيارات، القرار والمساران النهائيان.
- **src/ui.rs** و**src/menu.rs**: HUD وشاشات RTL والقوائم.
- **src/audio.rs**: طبقة البيئة والمؤثرات المتكيفة مع الخطر.
- **crates/astra_voxel_world**: نسخة محلية مرخصة MIT من مولّد العالم، بلا مسارات مطلقة خارج المشروع.
